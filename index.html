Politique de confidentialité — Coups de bébé

Dernière mise à jour : octobre 2026

1. Principe : tout reste sur votre appareil

L'application « Coups de bébé » fonctionne entièrement hors ligne. Les données que vous saisissez (sessions de comptage de coups, notes) sont enregistrées uniquement dans le stockage local de votre téléphone. Elles ne sont jamais envoyées sur nos serveurs, car il n'existe aucun serveur : pas de compte utilisateur, pas de base de données distante, pas de synchronisation cloud.

2. Achats intégrés (facturation Google Play)

Si vous achetez la version premium, la transaction est traitée par Google Play. Nous recevons, via notre prestataire RevenueCat, uniquement les informations nécessaires à la reconnaissance de votre achat : identifiant technique de l'appareil, historique d'achats et statut de l'abonnement. Ces données ne sont pas croisées avec le contenu de vos saisies de santé, que nous ne pouvons pas voir.

3. Export de données

Les exports (PDF) sont générés sur votre appareil et ne nous sont jamais transmis. Vous seul décidez de les partager (imprimante, messagerie, etc.).

4. Suppression des données

La désinstallation de l'application supprime définitivement toutes vos données de l'appareil. Vous pouvez aussi effacer les saisies une par une dans l'application.

5. Mineurs

L'application est destinée aux parents/aidants. Elle ne collecte aucune donnée sur l'enfant : les saisies restent sur votre téléphone.

6. Contact

Pour toute question : contact@tratralito.dev
